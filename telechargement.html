Pourquoi Windows (ou ton antivirus) peut t'avertir

SpectreIA n'est pas encore signé numériquement. Signer un logiciel coûte de l'argent chaque année et demande de vérifier une identité professionnelle : hors de portée d'un projet de fan gratuit, sans publicité ni abonnement. Sans cette signature, Windows SmartScreen affiche un avertissement la première fois qu'un fichier circule peu, même quand il est inoffensif.

Certains antivirus vont plus loin et bloquent ou mettent en quarantaine un fichier par heuristique : SpectreIA utilise des raccourcis clavier globaux et peut écouter un mot de réveil à la voix pour te répondre dans le jeu, deux comportements qui ressemblent, pour un moteur automatique, à ce que fait un logiciel malveillant. C'est un faux positif.

Au lancement

Si Windows affiche « Windows a protégé votre ordinateur », clique sur Informations complémentaires, puis Exécuter quand même.

Si un antivirus met un fichier en quarantaine

Restaure le fichier concerné (ou ajoute une exclusion pour le dossier d'installation de SpectreIA), puis relance l'application. Tant que le fichier reste bloqué, l'app ne redémarrera pas, même après avoir redémarré le PC : ce n'est pas un bug qui se résout en réessayant, le fichier manquant doit être restauré.

Why Windows (or your antivirus) may warn you

SpectreIA isn't digitally signed yet. Signing software costs money every year and requires verifying a professional identity: out of reach for a free fan project with no ads and no subscription. Without that signature, Windows SmartScreen shows a warning the first times a file is seen in the wild, even when it's harmless.

Some antivirus software goes further and blocks or quarantines a file by heuristics: SpectreIA uses global keyboard shortcuts and can listen for a spoken wake word to answer you in-game, two behaviors that look, to an automated engine, like what malware does. That's a false positive.

When you launch it

If Windows shows "Windows protected your PC", click More info, then Run anyway.

If an antivirus quarantines a file

Restore the affected file (or add an exclusion for SpectreIA's install folder), then restart the app. As long as the file stays blocked, the app won't start again, even after restarting your PC: it's not a bug that fixes itself by retrying, the missing file needs to be restored.

Ce que l'application fait vraiment

  • Elle passe uniquement par l'API officielle de Bungie, la même que DIM : elle ne lit pas la mémoire du jeu et ne modifie aucun fichier de Destiny 2.
  • L'intelligence artificielle tourne sur ton PC : tes questions ne partent jamais vers un serveur.
  • Gratuite, sans publicité, sans compte à créer en dehors de ton compte Bungie.
  • Chaque version publiée reste visible et téléchargeable sur la page des releases GitHub, avec son détail de changements.
