# SpectreIA

Compagnon IA gratuit pour Destiny 2, sous Windows. L'IA (Gemma 4) tourne sur ton PC grâce à Ollama.

- **Télécharger :** [dernière version](https://github.com/Davvou-Ai/SpectreIA/releases/latest)
- **Présentation :** https://davvou-ai.github.io/SpectreIA/

Ce dépôt contient uniquement les versions publiées et la page de présentation. Les mises à jour de l'application sont distribuées automatiquement depuis ses releases.

SpectreIA est un projet de fan indépendant, non affilié à Bungie. Destiny 2 est une marque de Bungie, Inc.
