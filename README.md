# SpectreIA

Compagnon gratuit pour Destiny 2, sous Windows. L'intelligence artificielle tourne sur ton PC.

- **Télécharger :** [dernière version](https://github.com/Spectre-IA/SpectreIA/releases/latest)
- **Site :** https://spectre-ia.github.io/SpectreIA/

Ce dépôt contient uniquement les versions publiées et le site. Les mises à jour de l'application sont distribuées automatiquement depuis ses releases.

SpectreIA est un projet de fan indépendant, non affilié à Bungie. Destiny 2 est une marque de Bungie, Inc.
